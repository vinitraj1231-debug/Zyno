### 5.1 Pre-Submission Google AdSense Checklist

Before submitting `https://zynochat.in` to Google AdSense, complete and verify every item on this checklist:

#### A. Core Web Vitals & Speed Optimization
- [ ] **LCP (Largest Contentful Paint):** `< 2.1s` on mobile 4G network.
- [ ] **FID/INP (Interaction to Next Paint):** `< 100ms`.
- [ ] **CLS (Cumulative Layout Shift):** `< 0.05` across all pages.
- [ ] **Assets Minification:** CSS, JS, and HTML minified and served via HTTP/2 or HTTP/3 with Gzip/Brotli compression.
- [ ] **Image Optimization:** All article images converted to WebP/AVIF formats with explicit `width` and `height` attributes to eliminate layout jumps.

#### B. Content Volume & Structure Checks
- [ ] **Article Threshold:** At least **15 to 20 long-form, peer-reviewed articles** published (minimum 1,500+ words per article).
- [ ] **Originality Check:** Zero duplicate content or automated spun AI text. Passed CopyScape or originality scanners.
- [ ] **Category Saturation:** Each category contains a minimum of 3-4 published articles (no empty categories or "Coming Soon" pages).
- [ ] **Navigation Menu:** Clear, desktop & mobile hamburger menu with links to Core Categories, About Us, Privacy Policy, Terms, and Contact Us.

#### C. Policy & Compliance Verification

### 5.2 Post-Approval Transition Strategy (Content Hub → Real-Time Web Platform)

Once Google AdSense approval is secured and initial domain authority is established, `zynochat.in` will transition into a hybrid model: an interactive real-time messaging application with an integrated technical knowledge hub.

#### Architectural Transition Plan:

```
[Phase 1: Pure Content Hub]
https://zynochat.in/ -> Static/SSR Blog Articles & Technical Guides (Fast AdSense Approval)

                 │  (After Approval & Traffic Growth)
                 ▼

[Phase 2: Hybrid Platform Architecture]
├── https://zynochat.in/          -> Real-Time Web Messaging App (SPA App Shell)
├── https://zynochat.in/hub/      -> Technical Knowledge Hub & Blog Articles
├── https://zynochat.in/api/ws    -> WebSocket Cluster (Node.js/Go/Redis)
└── https://zynochat.in/sitemap.xml -> Unified Dynamic Sitemap
```

#### Step-by-Step Transition Protocol:

1. **URL Sub-path Routing Preservation:**
   - Migrate blog articles seamlessly from `/blog/[slug]` to `/hub/[slug]` or maintain 301 redirects to avoid losing indexed search rankings or canonical authority.
   - Serve the primary dynamic web app on the root URL (`https://zynochat.in/`) using Server-Side Rendering (SSR) via Next.js, Nuxt, or Astro so that search engines can still index the homepage's value proposition.

2. **AdSense Compliance for Interactive Single Page Applications (SPA):**
   - **Dynamic Ad Loading:** Implement Google Publisher Tags (GPT) for SPA environments, calling `googletag.pubads().refresh()` upon page navigation or dynamic route updates without refreshing the entire browser window.
   - **Ad Placement Rules:** Ensure ads are strictly isolated from real-time messaging feeds (e.g., place non-intrusive sidebar ad banners or bottom sticky ads, never inside user-to-user chat streams to prevent accidental clicks or policy violations).

3. **Dynamic Content & Programmatic SEO Scaling:**
   - Allow public rooms/topics (e.g., `https://zynochat.in/rooms/webrtc-developers`) to generate SSR metadata and schema markup, turning public user-generated discussions into indexable content assets.
   - Maintain automated `sitemap.xml` updates whenever new public chat rooms or blog articles are published.
